# 黑神话悟空知识问答 RAG

## 功能
基于本地文档的智能回答，支持引用来源。

## 技术栈
- 文档加载：langchain
- 向量存储：Milvus Lite
- 大语言模型：DeepSeek
- Embedding： bge-small-zh-v1.5

## 使用方法
1. pip install -r requirements.txt
2. 配置.env的api_key
3. 执行build_index.py构建索引
4. 执行ask.py进行问答
5. 执行eval.py进行评测

## 评测
评测集在eval.py中，执行eval.py进行评测。
通过率：10/10 (100%)

## 项目结构说明

```
├── demo
│   ├── build_index.py      # 向量检索索引构建脚本，将文档转为向量并写入Milvus
│   ├── ask.py              # 问答主脚本，实现RAG问答（召回+大模型生成）
│   ├── eval.py             # 评测脚本，批量测试问答表现
│   ├── .env 
│   ├── load_data.py              # 加载数据脚本，将文档转为向量并写入Milvus
│   └── wukong_milvus.db             # 环境变量配置（API KEY等）
├── 黑神话data
│   ├── 设定.txt
│   ├── 黑悟空wiki.txt
│   ├── 黑悟空版本介绍.md
│   └── 黑神话悟空.csv    # 装备/技能/人物数据（含铜云棒、银角大王等）      
├── README.md               # 项目说明文档
└── requirements.txt        # Python依赖库
```

> 说明：所有知识数据或文档均放于 `黑神话data`下，Milvus保存向量索引为wukong_milvus.db。
> 示例与主流程代码集中于demo目录，按照推荐顺序依次执行相关脚本即可体验RAG全流程。
