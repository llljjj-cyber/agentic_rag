# 本地直接运行

适合开发调试：前后端热重载、断点调试。数据库推荐仍用 Docker 只起 Postgres 容器。

> 启动前请先完成 [环境变量配置](./环境变量配置.md)。

## 前置

- Python 3.10+
- Node.js 18+
- Docker（推荐，用于运行 PostgreSQL + pgvector）

## 1. 启动数据库

### 方式 A：Docker 只起 Postgres（推荐）

启动：

```bash
docker compose up -d postgres-db
```

在 `backend/.env` 中设置（用户名 / 密码 / 库名与根目录 `.env` 一致）：

```env
DATABASE_URL=postgresql+asyncpg://<POSTGRES_USER>:<POSTGRES_PASSWORD>@localhost:5432/<POSTGRES_DB>
```

### 方式 B：本机安装 PostgreSQL

安装 PostgreSQL 16 并启用 pgvector 扩展，然后配置 `DATABASE_URL` 指向本机实例。

---

## 2. 启动后端

在项目根目录执行（Python 包根为仓库根，import 形如 `backend.xxx`）：

```bash
cd backend
python -m venv .venv
```

激活虚拟环境：

```bash
# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate
```

安装依赖（需先装 CPU 版 PyTorch）：

```bash
pip install torch==2.9.1+cpu --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt
```

确认 `backend/.env` 中：

- `DATABASE_URL` 已指向可访问的数据库
- `ALLOWED_ORIGINS` 包含 `http://localhost:5180` 与 `http://127.0.0.1:5180`
- Embedding 与 LLM 相关变量已配置

回到项目根目录启动（必须设置 `PYTHONPATH=.`，否则找不到 `backend` 包）：

```bash
cd ..

# Windows PowerShell
$env:PYTHONPATH = "."
python -m backend.main

# macOS / Linux
# export PYTHONPATH=.
# python -m backend.main
```

等价写法：

```bash
# Windows PowerShell
$env:PYTHONPATH = "."
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8897 --reload

# macOS / Linux
# PYTHONPATH=. python -m uvicorn backend.main:app --host 0.0.0.0 --port 8897 --reload
```

后端地址：[http://localhost:8897](http://localhost:8897)  
健康检查：`GET http://localhost:8897/health`

---

## 3. 启动前端

新开一个终端：

```bash
cd frontend
npm install
```

确认 `frontend/.env`：

```env
VITE_API_URL=http://127.0.0.1:8897
```

启动 dev server：

```bash
npm run dev
```

前端地址：[http://localhost:5180](http://localhost:5180)（见 `frontend/vite.config.ts`）

---

## 访问地址汇总

| 服务 | 地址 |
|------|------|
| 前端（Vite dev） | [http://localhost:5180](http://localhost:5180) |
| 后端 API | [http://localhost:8897](http://localhost:8897) |
| 健康检查 | [http://localhost:8897/health](http://localhost:8897/health) |

与 Docker 模式的区别：本地模式下前端直连后端 `8897`，不经过 Nginx 反代。

## 启动后验证

1. 打开 [http://localhost:5180](http://localhost:5180)，注册 / 登录
2. 入库一段文本
3. 在对话中提问，确认检索与流式回复正常

## 常见问题

**CORS 报错**

- 检查 `backend/.env` 的 `ALLOWED_ORIGINS` 是否包含前端实际地址（含端口 `5180`）

**前端请求失败 / 连不上后端**

- 确认 `frontend/.env` 中 `VITE_API_URL=http://127.0.0.1:8897`
- 修改 `.env` 后需重启 `npm run dev`

**数据库连接失败**

- 确认 Postgres 容器在运行：`docker compose ps`
- 确认本机 5432 未被占用；compose 已默认映射到 127.0.0.1:5432，且 `DATABASE_URL` 用户名密码正确

**本地 Embedding 加载慢或失败**

- 确认 `BGE_MODEL_PATH` 为本机绝对路径
- API 模式：填写 `SILICONFLOW_API_KEY`，无需本地模型
